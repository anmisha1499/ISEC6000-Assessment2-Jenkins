# ISEC6000 Assessment 2 – Jenkins CI/CD

This repository contains the Docker Compose and Jenkins configuration developed for ISEC6000 Assessment 2.

## Purpose

The repository provides the containerised Jenkins environment used to implement and demonstrate the CI/CD pipeline for the Node.js application.

## Repository Structure

* `docker-compose.yml` – Defines the Jenkins controller and Docker-in-Docker services, persistent volumes, networking, and required Docker integration.
* `jenkins/Dockerfile` – Defines the custom Jenkins image used for the CI/CD environment.

## Jenkins Environment

The environment consists of:

* Jenkins controller
* Docker-in-Docker service
* Docker Compose
* Shared Jenkins workspace
* Persistent Jenkins home
* Docker TLS certificates
* Dedicated Jenkins Docker network

## CI/CD Application Repository

The pipeline source application is maintained in the following GitHub repository:

`https://github.com/anmisha1499/aws-elastic-beanstalk-express-js-sample`

The application repository contains the Node.js application, Docker configuration, and Jenkinsfile used by the pipeline.

## Docker Registry

Docker images generated by the pipeline are published to Docker Hub under:

`madakaanmisha/aws-elastic-beanstalk-express-js-sample`

## Assessment

This repository supports the Docker Compose and Jenkins configuration requirements for ISEC6000 Assessment 2, including containerised CI/CD execution and integration with the Docker environment.
